# threads-figures

Threads投稿（@kikucchi_shikaku）に添付する図解の置き場。

**このリポジトリが公開なのは、Threadsに画像を添付するために公開URLが必要だから。**
Buffer経由でThreadsに画像を送る場合、`assets: [{image: {url}}]` の url は
公開アクセス可能でなければならない。

- 中身は図解PNG（1080×1350・4:5）のみ。鍵・認証情報・個人情報は置かない
- 生成元は `【アカウントリサーチ】threads-note-growth-research/output/threads_figures.py`
- 参照URLの形：`https://raw.githubusercontent.com/<user>/threads-figures/main/img/<name>.png`
